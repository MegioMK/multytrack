# Сценарии использования

## Захват входящего

1. Пользователь пишет или пересылает сообщение боту.
2. Бот сохраняет оригинальный текст во `Входящие` и коротко подтверждает запись со ссылкой на лист.
3. Пользователь вносит или уточняет `Формулировку задачи` и при необходимости меняет `Предложенный тип`.
4. После двух минут без правок Apps Script создает задачу, рутину или покупку. Если результат нужен сразу, в меню таблицы выбрать `Таск-трекер -> Создать готовые задачи сейчас`.

Автодетекция: текст с ключевым словом `купить` предлагается как покупка. Рутину можно указать вручную во `Входящие`.

## Обычная задача

1. Во `Входящие` сформулировать задачу и оставить тип `задача`.
2. Автоматика создает строку в `Задачи` и базовую подзадачу с тем же названием.
3. В `Задачи` вручную задаются проект, приоритет и дедлайн.
4. Планирование и закрытие происходит на уровне `Подзадачи`.
5. Когда все подзадачи закрыты, задача получает статус `done`; если часть закрыта - `in_progress`.

## Несколько подзадач

Создайте дополнительные строки на листе `Подзадачи`, укажите `Задача ID`, название, дату и оценку. Название основной задачи подтягивается по ID. Подзадача с датой на сегодня появится в `Плане дня` и в сообщении бота.

## Рутина

1. Во `Входящие` выбрать `Предложенный тип = рутина`.
2. В `Рутины` указать правило повторения, дату следующего выполнения и статус `active`.
3. Apps Script создаст отдельную подзадачу на нужную дату.
4. Закрытие экземпляра обновляет `Последнее выполнение` и рассчитывает следующую дату.

Ежедневная рутина создает сегодняшний экземпляр даже при незакрытом вчерашнем.

## Покупка

1. Отправьте боту сообщение с `купить` или выберите тип `покупка` во `Входящие`.
2. Позиция появляется в `Список покупок` и отдельным блоком внизу `Плана дня`.
3. Покупка закрывается изменением статуса в своем листе. Связанная задача не удаляет позицию из списка.

## День и бот

- В 07:30 бот присылает план: рутины, задачи на сегодня, затем просроченные вчера. Сообщение содержит оценку общего времени, отдельно рутин и проектов.
- В 08:00, если есть неразобранные входящие, приходит напоминание.
- В 08:30 приходит список покупок.
- В 20:00 бот присылает повтор плана с напоминанием закрыть или перенести незавершенное.
- `/today` показывает актуальный план; `/hot` - просроченные; `/shopping` - активные покупки. `Done` закрывает подзадачу, а `Куплено` закрывает позицию списка покупок.
- С момента включения аналитики дата каждого закрытия фиксируется автоматически. На ее основе создаются ежедневные строки в `Сводки` и недельные цифры в `Итоги недели`.
- После 12:00 в четверг бот предлагает недельную рефлексию. Пользователь отвечает на каждый вопрос реплаем; ответы сохраняются в строку завершенного недельного цикла и не смешиваются с Входящими.
