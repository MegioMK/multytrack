# Контракт Google Таблицы

## Ручные поля

Заголовки ручных полей выделяются цветом в самой таблице. Автоматика не должна менять этот цвет или заменять правила выпадающих списков.

| Лист | Ручное действие |
| --- | --- |
| Входящие | Формулировка результата, тип, решение по строке. |
| Задачи | Проект, приоритет, дедлайн, уточнение названия. |
| Подзадачи | Название, дата, оценка, статус. |
| Рутины | Название, правило повторения, следующая дата, статус. |
| Покупки | Статус позиции при покупке. |
| Справочники | Редактирование единого набора значений. |

## Сводки и итоги недели

Автоматика добавляет столбец `Дата закрытия` в Задачи, Подзадачи и Список покупок. Он заполняется при выборе `done` и очищается, если строку снова открыть. Это служебное поле: вручную его менять не нужно.

- В `Сводки` в 23:30 создается или обновляется один снимок текущего дня: закрытые дела, покупки, минуты, входящие, просрочки и нагрузка по проектам.
- В `Итоги недели` после 12:00 в четверг появляются цифры за цикл «четверг 12:00 — четверг 12:00». В начале листа идут девять ручных полей рефлексии: главный результат, энергия и фокус, что сработало, напряжение и откладывание, урок, коммуникация, система работы, рост и следующий цикл. За ними расположены автоматические показатели.
- Ответ попадает в рефлексию только когда пользователь отвечает именно на текущее сообщение-вопрос бота. Любое другое сообщение по-прежнему становится Входящим.
- В меню `Таск-трекер` есть команды для немедленного создания сводки за сегодня или итогов текущей недели. Повторный запуск обновляет ту же строку, а не создает дубль.
- Исторические закрытия до появления `Дата закрытия` не восстанавливаются задним числом: достоверная динамика начинает собираться после включения функции.

## Статусы

Для Входящих, Задач, Подзадач и Покупок используются: `new`, `planned`, `in_progress`, `blocked`, `done`, `cancelled`, `skipped`.

`done` означает, что работа выполнена. `cancelled` означает, что ее сознательно отменили. `skipped` означает, что строку решили не обрабатывать без утверждения, что работа выполнена.

Для Рутин используются отдельные статусы: `active`, `paused`, `archived`.

## Инварианты

- Каждая новая задача получает одну базовую подзадачу.
- Статус задачи вычисляется по подзадачам; он не является независимой ручной правкой.
- Подзадача с датой сегодня появляется в Плане дня.
- Проект задачи распространяется на ее подзадачи и используется в расчете нагрузки.
- `План дня` - витрина: не создавайте в нем вручную основные сущности.
