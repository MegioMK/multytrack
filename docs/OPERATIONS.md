# Эксплуатация

## Регулярная работа пользователя

- Бот служит входной точкой и быстрым закрытием; управление структурой задач идет в таблице.
- Утром проверить `План дня`, закрыть завершенное или перенести дату подзадачи.
- Во `Входящие` разобрать новые строки: сформулировать результат и выбрать тип.
- Проект, приоритет и дедлайн указывать на задаче; дата и оценка - на подзадаче.

## Расписание

| Время | Действие |
| --- | --- |
| Каждую минуту | Проверка Входящих, не менявшихся две минуты, и служебные обновления. |
| 07:30 | Утренний план. |
| 08:00 | Напоминание о неразобранных Входящих, только если они есть. |
| 08:30 | Список покупок. |
| 20:00 | Вечерний план с числом закрытых за день дел и оставшимися пунктами. |
| 23:30 | Автоматический снимок дня в листе `Сводки`. |
| Воскресенье после 23:40 | Автоматические цифры в строке `Итоги недели`. |

Часовой пояс триггеров задается в настройках Apps Script проекта.

## Диагностика

| Симптом | Проверка |
| --- | --- |
| Бот молчит | `getWebhookInfo`, логи Worker, затем логи Function. |
| Сообщение не записалось | `ALLOWED_CHAT_ID`, доступ service account к таблице, логи Function. |
| Задача не создана | Подождать задержку черновика, проверить формулировку и тип, вручную запустить `Обновить всё сейчас`. |
| Нет утреннего сообщения | Проверить Apps Script Executions, свойства relay и установленный триггер. |
| План не обновился | Проверить формулы и заголовки с 11-й строки; запустить `Обновить всё сейчас`. |

## Восстановление

`Таск-трекер -> Создать готовые задачи сейчас` обрабатывает уже заполненные Входящие без ожидания. Команда `Таск-трекер -> Восстановить автоматизацию` пересоздает триггеры и запускает обновление, не удаляя данные. Если изменение кода Apps Script требует новых разрешений, выполнить функцию из редактора вручную и подтвердить доступ.
