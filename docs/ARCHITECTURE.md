# Архитектура

## Поток данных

```text
Telegram -> Cloudflare Worker -> Yandex Cloud Function -> Google Sheets API -> Google Таблица
Google Apps Script -> Cloudflare Worker -> Telegram
```

`Cloudflare Worker` - единственная публичная точка Telegram webhook. Он проверяет webhook-secret и передает update в Yandex Function. Для исходящих сообщений Apps Script и Function обращаются к Worker с `X-Relay-Secret`; Worker отправляет вызов Telegram Bot API, не раскрывая токен.

`Yandex Cloud Function` принимает текстовые и пересланные сообщения, команды `/today`, `/hot`, `/help` и callback-кнопки `Done`. Она работает с таблицей через Google Sheets API от имени сервисного аккаунта.

`Google Apps Script` привязан к таблице. Он поддерживает структуру листов, преобразует готовые Входящие в Задачи или Рутины, создает экземпляры рутин, строит План дня, агрегирует статусы и отправляет сообщения по расписанию.

## Граница ответственности

| Компонент | Отвечает за | Не отвечает за |
| --- | --- | --- |
| Telegram bot / Function | Захват сообщений, команды, кнопки закрытия. | Бизнес-правила планирования. |
| Apps Script | Состояние и автоматизация таблицы. | Прием Telegram webhook. |
| Google Sheets | Единственный источник данных пользователя. | Хранение секретов. |
| Cloudflare Worker | Relay и защита публичной точки. | Логика задач. |

## Листы

Во всех рабочих листах строки 1-10 предназначены для ручного дашборда, строка 11 содержит заголовки, данные начинаются с 12-й строки.

| Лист | Назначение |
| --- | --- |
| `Входящие` | Необработанные сообщения и ручная формулировка результата. |
| `Задачи` | Основные задачи, их проект, приоритет, дедлайн и агрегированный статус. |
| `Подзадачи` | Атомарные действия; их статус является источником статуса задачи. |
| `Рутины` | Правила повторяющихся дел. |
| `Список покупок` | Отдельный поток покупок; не исчезает при создании связанной задачи. |
| `План дня` | Формульная витрина на просроченное, сегодня, завтра и покупки. |
| `Справочники` | Источник выпадающих списков. |
| `Настройки` | Локальные настройки нагрузки и расписаний. |
| `README` | Объяснение листов для пользователя. |
