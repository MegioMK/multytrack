# Multytrack Repository Rules

- В репозитории запрещены реальные названия задач, сообщения, chat ID, spreadsheet ID, URL развертываний, токены, ключи сервисных аккаунтов и персональные данные.
- Настройки конкретного пользователя живут в Google Sheets и облачных секретах, не в Git.
- Любой новый пример должен быть обезличен: например, `Подготовить отчет`, а не реальная рабочая формулировка.
- Перед коммитом выполнить проверку из `docs/TESTING.md` и убедиться, что `git status` не содержит `.env`, ключей или экспортов таблицы.
- Изменения интерфейса Google Sheets должны сохранять правило: строки 1-10 зарезервированы под дашборд, заголовки находятся в строке 11, данные начинаются со строки 12.
